# 格式化 Rust 代码

## 概述

自动格式化项目中的所有 Rust 代码文件，使用 `rustfmt.toml` 中定义的配置规则。

## 使用场景

- 每次编辑代码后必须运行
- 保存文件后格式化代码
- 提交代码前确保格式一致
- 团队协作时统一代码风格

## 功能

执行 `cargo fmt --all` 命令，自动格式化：
- 所有 `.rs` 源文件
- 包括主程序、库代码、测试代码
- 遵循 `rustfmt.toml` 配置

## 配置

格式化规则由项目根目录的 `rustfmt.toml` 文件控制：
- 最大行宽：100 字符
- 缩进：4 空格
- 函数参数布局：Tall
- 字段初始化简写：启用

## 执行

```bash
cargo fmt --all
```

格式化完成后会自动修改文件内容，无需手动操作。

## 最佳实践

建议配合编辑器的"保存时自动格式化"功能，确保每次保存文件时自动运行格式化。
