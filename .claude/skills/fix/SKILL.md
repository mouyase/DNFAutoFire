# 自动修复代码问题

## 概述

自动修复代码中可以自动修复的问题，包括：
1. 格式化所有代码文件
2. 自动修复 Clippy 可以处理的代码质量问题

## 使用场景

- 发现格式或 lint 问题时快速修复
- 批量清理代码问题
- 重构后快速规范化代码
- 团队协作时统一代码风格

## 功能

执行两个步骤：

### 步骤 1: 格式化代码
```bash
cargo fmt --all
```

### 步骤 2: 自动修复 Clippy 问题
```bash
cargo clippy --all-targets --all-features --fix --allow-dirty --allow-staged
```

自动修复包括：
- 不必要的类型转换
- 未使用的导入
- 可简化的代码模式
- 明显的性能优化
- 其他 Clippy 可自动修复的问题

## 注意事项

### ⚠️ 重要警告

1. **代码可能被修改**：自动修复可能会改变代码逻辑（虽然罕见）
2. **建议检查更改**：修复后使用 `git diff` 检查所有更改
3. **运行测试**：修复后务必运行测试确保功能正常

### 无法自动修复的问题

某些 Clippy 警告需要手动修复：
- 复杂的逻辑重构
- 架构级别的改进
- 需要业务理解的优化

## 执行后检查

修复完成后，建议立即运行：

```bash
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all
```

或直接运行 `/check` skill。

## 最佳实践

1. 修复前先提交当前更改（便于回滚）
2. 修复后仔细检查 git diff
3. 确保所有测试通过
4. 对于关键代码，手动审查修复内容
